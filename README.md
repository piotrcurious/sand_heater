# sand_heater
sand heater for thermal energy storage junkbox

This project aims at designing crude, DIY sand heater. 
It should store energy (electric) in form of high temperature sand when it is available (5h of solar input) and then slowly radiate it out for at least 18h of 300W output. 

it should be simple to make in garage without Fancy tools or materials, and push the thermal comfort of a space it is placed into slightly. 
Of course it should be cheap.
